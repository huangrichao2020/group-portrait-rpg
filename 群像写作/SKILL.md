# 群像写作 skill · group-portrait-writing

> 群像小说的本质：**多个角色的诉求在同一时空碰撞，谁也不让谁，谁也跑不掉**。
> 不是"主角视角切换 + 配角工具人"，而是"每个角色都有自己的弧光，每个人都在被自己的住相推着走"。

## 它是什么

一个**群像小说方法论 skill**。它告诉你：
- 群像 vs 单主角的本质区别（不是"切换视角"，是"诉求独立"）
- 群戏三要点（**人人有私心 / 行动力对等 / 暗线同步**）
- 死光节点四要素（**引信 / 撞车 / 余震 / 落点**）
- 住相方法论（**表层住相 → 深层住相 → 闭环冲突**）
- 群戏的节奏感（**冷场 → 暗涌 → 咬合 → 炸裂**）

## 什么时候用

- ✅ 用户说"我想写一个群像故事 / 多线叙事 / 几个主角的小说"
- ✅ 用户想写 ≥ 3 个核心角色共同推进的小说
- ✅ 用户已有的单主角故事想扩成群像
- ❌ 不适用于单主角单一视角故事
- ❌ 不适用于纯对话体（剧本 / 对话录）

## 核心方法论（5 条铁律）

### 1 · 人人有私心
**每个角色必须有独立的 `want`（核心诉求），且 want 之间必须能撞车**。
群像不是"几个好人一起做事"，是"几个人各有算计，挤在同一张桌子上"。

### 2 · 行动力对等
**每个角色都要有"主动推剧情的能力"**，不是被动等主角来推动。
群像 = 主角视角不停切换，但每个视角里的角色都是自己的主角。

### 3 · 暗线同步
**每个角色的 `secret`（秘密 / 暗线）要在不同时间点错落揭示**，不能一次性全揭。
群像的爽感来自"读者知道 A 的秘密但 B 不知道"的信息不对称。

### 4 · 死光节点
群像必须有**一个所有诉求同时撞车的最高潮节点**——所有人被逼到同一个角落，所有人的算盘被碾碎。
这个节点之前是"埋"，之后是"收"。

### 5 · 住相闭环
每个角色必须有**表层住相 → 深层住相的弧光闭环**——
表层：角色嘴上说的 / 表面在做的事
深层：角色真正想要的 / 真正在逃避的事
弧光 = 表层与深层的撕扯 + 闭环（达成 / 失败 / 留白）

## 设计蓝图（5 步写一篇群像）

1. **定场域**：把 ≥ 3 个角色塞进同一个时空（饭局 / 春节 / 董事会 / 婚礼 / 同学会 / 末日电梯…）
2. **立角色卡**：每人填 `want` / `mask` / `secret` / `arc` 四件套（参 `essay-methodology.md`）
3. **排暗线**：每个角色的秘密设定"什么时点揭示"（群像节奏的核心）
4. **设死光节点**：一句话写下"所有诉求同时撞车的瞬间"——这是全剧最高潮
5. **写撞车段**：死光前 3-5 段铺垫 + 死光本身 1 段爆发 + 死光后 1-2 段收尾

## 与群像文字游戏模板的关系

- **群像写作** = 把一篇群像文**写得好看**（方法论）
- **群像文字游戏模板** = 把一篇群像文**变成可玩的游戏**（生成器）
- 配合使用：先用本 skill 打磨群像文骨架 → 再用群像文字游戏模板把它实例化成可玩 skill
