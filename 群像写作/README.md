# 群像写作 skill

> 把群像故事**写得好看**的方法论。

## 一句话
**多人诉求在同一时空碰撞，谁也不让谁，谁也跑不掉** —— 不是"主角视角切换 + 配角工具人"。

## 5 条铁律
1. **人人有私心**——每个角色独立 want，能撞车
2. **行动力对等**——每个角色都主动推剧情
3. **暗线同步**——秘密错落揭示，制造信息不对称
4. **死光节点**——所有诉求同时撞车的最高潮
5. **住相闭环**——表层住相 → 深层住相 → 弧光

## 5 步写一篇群像
定场域 → 立角色卡 → 排暗线 → 设死光节点 → 写撞车段
