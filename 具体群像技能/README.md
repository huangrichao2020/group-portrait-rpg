# 🎭 群像文字游戏 · 独立 skill 集

> **对外可发**——本目录下每一个文件夹都是一个**完整的、可独立加载运行的群像文字游戏 skill**。
> 你可以直接把任意一个文件夹（连同 `SKILL.md` + `game-data.json`）打包发给朋友，他们丢给任意 Agent 就能开一局。

## 它是什么

每一局游戏 = 一场"群像戏"，玩家以**第七人**身份卷入同一事件，中途不断做判断与真实答复，改写人物关系、推动剧情，最终在"死光节点"引爆所有诉求的碰撞。

## 怎么分享一个 skill

把对应文件夹整个打包（如 `01-饭局-最后一顿散伙饭/`）即可。**不要包含父目录的 README**——README 只是给你自己看的"速查表"。

> **温馨提示**：发给别人前，把 `SKILL.md` 和 `game-data.json` 里的玩家身份（如"{玩家昵称}"）改成对方的昵称或角色，代入感会更强。

## 新做一个新场景

1. 复制任意一个实例文件夹，改名；
2. 按 SKILL.md 里的"游戏设定"字段填新内容（meta/venue/cast/trigger/branches/endings 六块）；
3. game-data.json 按 SKILL.md 附录里的 schema 字段填；
4. 改完直接发人，无需打包其他东西。

## 30 秒上手

加载任一 `SKILL.md` 到 Agent，Agent 化身 DM（主持人），按其内部指令带你走完一局。**首次加载会自动创建 `./saves/` 存档目录**，下次玩可从断点续玩。
