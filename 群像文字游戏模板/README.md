# 群像文字游戏模板 · 总览（公共模板）

> **📖 说明**：这是**公共元模板**，复制后自由使用，欢迎提 PR。
> 对外只发 `群像文字游戏/` 下的具体实例 skill。

一场群像文，就是一场"局"。这个模板把群像文变成**可在 Agent 里沉浸式游玩的文字游戏**——
玩家是"第七人"，中途不断做判断、给真实答复，改写人物关系、推动剧情，最终在"死光节点"引爆所有诉求的碰撞。

## 它能干嘛

- **写→玩闭环**：配合「群像写作 skill」打磨群像文，再用本模板把它变成可玩的游戏 skill。
- **批量产游戏**：一台群像文 = 一个具体文字游戏 skill。一条生产线，产出各式各样的沉浸式剧本。
- **真·分支叙事**：玩家输入被"记住"，NPC 按自己私心行事，世界不围着玩家转。

## 目录

| 路径 | 作用 |
|------|------|
| `SKILL.md` | 元模板 + 实例化配方（5 步把群像文变成游戏 skill） |
| `fixed/schema.md` | 游戏数据 schema（每个字段的类型/含义/示例） |
| `fixed/genres.json` | 场景预设：饭局/家族春节/董事会/婚礼/同学会/密室 |
| `workflow/dm-runtime.md` | 主持人运行流：布场→入局→缠绕→死光→复盘 |
| `实例/饭局文字游戏/` | 已产出的具体游戏 skill，可直接加载游玩 |

## 30 秒上手

1. 想做一个新游戏：复制 `实例/饭局文字游戏/` 文件夹，改名；
2. 按 `fixed/schema.md` 填 `game-data.json`（5 步配方）；
3. 把 game-data 内联进新 `SKILL.md` 的运行指令段；
4. Agent 加载该 `SKILL.md`，化身主持人，开一局。

## 设计蓝本

schema 抽取自 `novel-evolution` 的动态库范式：
- `relationships.md`（人物关系库）→ 角色卡 + 关系网
- `world-state.md`（世界状态/暗线）→ 场域 + 裹挟事件 + 世界暗线
- `active-threads.md`（主线/支线/伏笔）→ 死光节点 + 分支点
- 三 agent（outline/draft/review）→ 布场 / 演出 / 复盘 三幕

并复用其"模板 = `fixed/`(方法论+配置) + `workflow/`(执行流)"的目录结构，做了纯提示词、零后端的简化。
