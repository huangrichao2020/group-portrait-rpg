# group-portrait-rpg · 群像文字游戏全家桶

> **"把群像文变成能玩的文字游戏"** —— 一个完整的"写得好看 → 变得好玩 → 直接玩"生产线。

## 它是什么

这是一个**三合一**仓库：

| 模块 | 定位 | 你能拿它干嘛 |
|---|---|---|
| **[群像写作](./群像写作/)** | 方法论 | 写一篇群像小说 / 多角色故事 |
| **[群像文字游戏模板](./群像文字游戏模板/)** | 元模板 / 生成器 | 把一篇群像文**自动**变成可玩的文字游戏 skill |
| **[具体群像技能](./具体群像技能/)** | 可玩游戏 × 5 | 直接加载一个游戏，立刻开一局 |

## 5 个可玩实例

- `01-饭局-最后一顿散伙饭` — 6 人散伙饭，死光 = A 宣布离开杭州
- `02-家族春节-最烦那顿饭` — 被妈逼回老家过年，4 个代理点 + 死光 = 奶奶问"你图个啥"
- `03-公司董事会-空降第二天` — 空降第二天站队抉择
- `04-婚礼现场-伴郎的秘密` — 伴郎视角的婚礼修罗场
- `05-同学会-十年再聚` — 中年同学会的旧账攀比

每个实例都是一个**完整、可独立加载运行的群像文字游戏 skill**——丢给任意 Agent 就能开一局。

## 30 秒上手

```bash
# 1. 选一个实例
cd 具体群像技能/01-饭局-最后一顿散伙饭

# 2. 把 SKILL.md 加载到你的 Agent（Claude Code / ChatGPT / 任何支持 Skill 的 Agent）

# 3. Agent 化身 DM（主持人），带你走完一局
#    首次加载会自动创建 ./saves/ 存档目录
```

## 设计哲学

**沉浸式体验优先**：
- 玩家是"第七人"——不是看客
- 中途做判断和真实答复，改写人物关系
- 死光节点引爆所有诉求的碰撞
- 静默存档，玩家感觉"被记住了"而非"被存档了"
